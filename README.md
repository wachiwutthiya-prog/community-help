# ชุมชนช่วยกัน

เว็บไซต์ต้นแบบภาษาไทยสำหรับแจ้งปัญหาในชุมชนและติดตามสถานะ เหมาะสำหรับนำไปสาธิตเป็นโครงงาน

## วิธีเปิดใช้งาน

เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งโปรแกรมเสริมหรือจ่ายค่าใช้บริการ

## ฟีเจอร์

- แสดงภาพรวมและรายการปัญหาจากฐานข้อมูล Supabase
- กรองปัญหาตามหมวดหมู่
- กดสนับสนุนรายการปัญหา
- ส่งปัญหาใหม่ผ่านแบบฟอร์มและบันทึกใน Supabase
- เลือกโหมดสว่างหรือโหมดมืด โดยจำค่าที่เลือกไว้ในเบราว์เซอร์
- รองรับหน้าจอมือถือและคอมพิวเตอร์

รายการปัญหาที่แสดงมาจากฐานข้อมูล Supabase ที่ตั้งค่าไว้ใน `script.js` การส่งรายงานต้องเปิดสิทธิ์เพิ่มข้อมูลในฐานข้อมูลให้ถูกต้อง
